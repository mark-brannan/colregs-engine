# Gemini review of proposal v3 — 2026-09-04

Reviewer: Gemini 3.1 Pro (high) via agy 1.1.26, headless. Verbatim output.

1. **Category Partition** (Severity: Blocker)
*Target:* "Every *paragraph* carries exactly one category." and the table entries for 13(a).
*Issue:* The table assigns Rule 13(a) to both `classification` (13(a)–(c)) and `precedence` ("13(a) effect"), violating the strict 1:1 invariant. Furthermore, 14(c) (vessels in doubt default to head-on) is epistemic and fits `classification` better than `conduct`.
*Fix:* Alter the schema to allow multiple categories per paragraph, or strictly split 13(a) into synthetic sub-identifiers (e.g., `13(a)-status`, `13(a)-override`) in the data model. *(Expertise: Data modelling)*

2. **Rule 2 Region & Adversary** (Severity: Serious)
*Target:* "`✎ adversary` — *A* is computed two ways from the start... Which cells humans want to look at is what settles it."
*Issue:* The definitions of R0/R1/R2 are standard and well-formed safety games. However, adversary choice *A* is not the primary open question; the time horizon *T* is. A short *T* hides R1/R2 behind the horizon until it is too late; a long *T* causes rapid state space explosion in timed games.
*Fix:* Add time horizon *T* to the `✎ adversary` pencil block as a critical, co-dependent parameter to resolve alongside *A*. *(Expertise: Formal verification)*

3. **Outputs & Guard Rail** (Severity: Blocker)
*Target:* "advisories: the safe escape strategies the solver found, possibly none, each with the paragraphs it breaks and its margin."
*Issue:* Providing a menu of multiple rule-breaking advisories for a human to parse during R1 (imminent collision) is actively dangerous. Mentally evaluating violation margins and cross-referencing broken paragraphs takes time a mariner in extremis does not have, inducing fatal cognitive overload.
*Fix:* Constrain the output in R1 to emit only the single highest-margin escape trajectory, or suppress advisories entirely and emit only the R1 banner to trigger human instinct. *(Expertise: Seamanship)*

4. **Tractability Proxies** (Severity: Serious)
*Target:* "violation cost — paragraphs the cheapest escape breaks (R1 only)."
*Issue:* "Cheapest" is uncomputable because the proposal defines no cost function or severity hierarchy among rules (e.g., does breaking Rule 14 carry a higher cost than breaking Rule 15?).
*Fix:* Explicitly define a formal partial order of rule violation severity, or change the proxy definition to "the *fewest* paragraphs broken". *(Expertise: Data modelling / Formal verification)*

5. **Unjustified Ink** (Severity: Minor)
*Target:* **Ink, outputs in the region.** / "`✎ offline vs runtime`... Settled by the first two-vessel computation's cost."
*Issue:* If offline vs runtime computation is still in pencil, stating in ink that the engine emits what "the solver found" is a contradiction. If solved offline, the runtime engine only performs a state-space grid lookup and interpolation, it does not run a solver.
*Fix:* Demote the runtime generation of advisories to pencil, or rewrite the ink to state that the engine queries a pre-computed region grid. *(Expertise: Software architecture)*

Verdict: approve with changes.
