# colregs-engine — working conventions

Design docs mark each decision as **ink**, **pencil** (`✎`) or **open**
(`?`). Read [docs/conventions.md](docs/conventions.md) before changing any
design document: the marker is the rule for who may change the item and on
what grounds. Never edit an ink item; argue for it with evidence instead.

Requirements and ADRs for the data live in the `colregs` repo; this repo
holds the evaluator and its proposals.
